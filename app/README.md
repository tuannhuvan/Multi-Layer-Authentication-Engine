# Ứng Dụng Di Động Học Đường (Mobile Application)

Ứng dụng di động Native / Cross-platform (React Native / Flutter) dành cho Học sinh, Phụ huynh và Giáo viên:

## Các chức năng chính:
- `auth/`: Đăng nhập SSO qua Authenticator Service, xác thực sinh trắc học (Fingerprint / FaceID).
- `attendance/`: Điểm danh nhanh theo tiết học (dành cho Giáo viên) và theo dõi chuyên cần (Học sinh).
- `grades/`: Tra cứu kết quả học tập, thông báo điểm thi tức thời.
- `payment/`: Tích hợp SDK thanh toán học phí trực tuyến (VNPAY, MoMo).
